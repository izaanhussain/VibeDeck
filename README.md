# VibeDec
A custom 9-key programmable macropad built around the XIAO RP2040. # VibeDeck 🎛️

VibeDeck is a small 9key macropad that I am currently designing and building from scratch.

This is a simple project that has only one goal: make 9 mechanical keys for whatever macros/shortcuts I need, have an EC11 rotary encoder for volume and other functions, and have an OLED to display information.

The XIAO RP2040 is the brain of this operation. The design is taking place in KiCad.

# Bill of Materials

- 9 mechanical keys (3x3 matrix)

- XIAO RP2040 dev board

- EC11 rotary encoder with push button

- 0.91" 128x32 OLED

- 9x 1N4148 signal diodes

- Custom PCB

- Custom case (in the future 👀)
